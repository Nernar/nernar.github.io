# Going Forward

After the necessary [tools or environments are installed](supporting-ides), you can proceed directly to learning languages and creating a project. Regardless of the chosen programming language and project idea, it is important to maintain interest and motivation, as programming can be a complex and lengthy process.

## Learning Languages

Regardless of what content is planned for implementation, it is necessary to know at least the basics of the [syntax of one of the available languages](#why-syntax-is-needed) and be able to use it. The main language of our edition of Minecraft is C++, almost any idea can be implemented on it, but this will require a significant amount of time. A simpler solution, especially for beginners, would be to use JavaScript directly to work with the Core Engine. Most of the Inner Core pack is directly written in Java to interact with Android interfaces, which can be used to create integrations between native (device-native) C++ and other mods, or just for optimization.

Here is a list of some resources that can help you start learning languages:

- JavaScript — [javascript.info](https://javascript.info/), limit yourself to just the first chapter, we won't need browser features
- TypeScript — [TypeScript Handbook](https://www.typescriptlang.org/docs/), but only after learning JavaScript
- Java — [Java Tutorial](https://www.w3schools.com/java/), excluding most of the latest language features due to the compact edition
- C++ — [learn.microsoft.com](https://learn.microsoft.com/en-us/cpp/cpp)

Most of the documentation uses JavaScript, or concurrently, TypeScript, to obtain additional syntactic "sugar" and simplify code writing. We will not recommend which language to use, since everything is limited only by your idea and desire to work with different languages. Yes, you can use several, and yes, it doesn't end there.

:::warning You cannot simply use Forge mods

Despite Java being supported by default, not only does Android contain a special, compact version of Java SE, but the computer version of the game uses its own interfaces to interact with the game. The only thing that can really be used is algorithms, if this does not violate the license conditions of a particular project.

:::

## Why Syntax is Needed

Syntax in programming languages defines the rules and structure that must be observed when writing program code. It determines how instructions and expressions should be organized and written so that the device can interpret them correctly and understandably.

- Understandability for the device — processors work in accordance with certain rules and structures. The syntax of a programming language allows the device to understand and correctly interpret instructions, which allows it to perform tasks and operations.

- Readability for programmers — well-structured and clear syntax makes the code more readable and understandable for other programmers. This is especially important when working together on projects.

- Error prevention — syntactic rules help prevent errors in the code. If the code does not comply with syntactic rules, the compiler or interpreter of the programming language will report an error, which will allow the programmer to fix it.

Understanding and observing the syntax of a programming language is an important skill for developers to create correct and working code. You can use various resources, such as online courses, textbooks, video tutorials and practical assignments, to understand and apply language concepts in practice.

## Conceptualization

Before creating a new project, it is important to think over its purpose, development stages and calculate the time until the completion of the first, at least partially working, alpha version. This will contribute to more effective and successful modification development:

- Define goals and directions — designating the purpose of the modification helps to clearly formulate its goals and objectives. This allows the developer to have a clear idea of what he wants to achieve and what gameplay elements should be implemented.

- Plan ahead — developing a modification requires good planning and project management. Determining the stages of development and calculating the time until the release of the first alpha version helps organize work, allocate resources and set realistic deadlines for completing tasks. It allows identifying potential problems or difficulties in advance, as well as taking measures to prevent or eliminate them.

- Assess complexity and volume of work — calculating the time until the first testing allows assessing the complexity and volume of work associated with the development of the modification. This helps the developer to more accurately assess the resources needed to implement the project and plan the work accordingly.

It is important to remember that mod development requires practice, patience and constant study of new concepts and possibilities. There is no need to thoroughly study every article here, start with something small and move through basic concepts devoting literally 20-30 minutes a day. Believe me, this will be enough to expand the capabilities of the game, only desire and a creative approach are needed.
