# FAQ — Frequently Asked Questions

<details>
<summary>What is Horizon Modding Kernel?</summary>
<div>

*Horizon Modding Kernel* is a flexible game modding launcher, and above all, a mod loader for Minecraft: Bedrock Edition (and possibly other games in the future) on any Android device.

:::info Key features of Horizon Modding Kernel

- Creating mods for any games that are on your device
- Replacing existing game resources and adding new ones
- Flexible API that allows creating stable and powerful environments for game modding
- Additional support capabilities for Unity, as well as C/C++ applications

:::

You can run mods for Minecraft: Bedrock Edition, the loader provides full backward compatibility with mods for *Inner Core*. In addition, the launcher has an extensive amount of new functionality, the used version of Minecraft has been updated, and the existing functionality has been refined and stabilized.

All mods developed for Inner Core can be run using Horizon, most of the ports of large mods, such as Industrial Craft, Forestry, Harvest Craft, Blood Magic, etc., have been additionally optimized to work in Horizon.

</div>
</details>

<details>
<summary>Where can I find the current version of the launcher?</summary>
<div>

To start playing with mods, you will need Horizon, in which you will need to load Inner Core.

Download the latest version from [this link](https://drive.google.com/file/d/14SBKQSYbMGRT-Z5_cowYVfYiWTKD605c/view) and install it, allowing [installation from third-party sources](https://www.androidcentral.com/unknown-sources). Open the application and download the *Inner Core* pack (or *Inner Core Test* if you wish to receive updates slightly more often than others), *Inner Core Legacy* is outdated and is not recommended for installation.

The application may restart to complete the installation, now you can install the desired modifications using the *Mod Browser* on the pack's main page. To run the modified game, according to the license terms, you must have Minecraft installed. If you do not have it, you can [download a dummy](https://github.com/nernar/minecraft-stub/releases) without the game itself, it does not take up space and allows the launcher to run. Have a good game!

To get the full instructions, open [this documentation page](/docs/getting-started/installing-pack#lets-start-with-the-launcher).

</div>
</details>

<summary>External packs are unavailable. You can download and install them manually. What to do?</summary>
<div>

If external packs are unavailable, most likely the communication provider blocks access to [gitlab.com](https://gitlab.com) where all versions of *Inner Core* are located. Almost any VPN will help, after downloading it will not be needed. If the problem is not this, check the [site status](https://status.gitlab.com/), perhaps you just need to wait a little.

</div>
</details>

<details>
<summary>The mod browser does not download anything, what to do?</summary>
<div>

If the mod browser is unavailable, most likely the communication provider blocks access to [icmods.mineprogramming.org](https://icmods.mineprogramming.org) where all mods and modpacks of *Inner Core* are located. Almost any VPN will help, after downloading it will not be needed. If the problem is not this, perhaps you just need to wait a little.

</div>
</details>

<summary>Can I play with friends over the network?</summary>
<div>

To play over the network remotely, the device whose world other players want to join must be connected to Wi-Fi. All players must sign in to Xbox Live and add each other as friends (via the tab in the game's main menu). If there are problems, write [to our Discord](https://discord.gg/UbmjP8zeFz), we will try to solve your problem.

Want more? Download the [ZoteCore server core](https://github.com/Reider745/ZoteCoreLoader/actions), all further instructions can be found here: [Reider745/ZoteCoreLoader](https://github.com/Reider745/ZoteCoreLoader/blob/NukkitMot/README-RU.md).

</div>
</details>

<details>
<summary>Why does the launcher crash periodically on startup?</summary>
<div>

Sometimes crashes happen, this does not happen so often, but sometimes it happens. We have a choice: no crashes on startup, but with crashes in the game, or only sometimes on startup. If the problems persist, you can stop the application and clear the cache, this is enough in most cases.

</div>
</details>

<details>
<summary>I have a <i>.icmod</i> archive, how can I install it?</summary>
<div>

This is a regular zip-archive, change its format if you have problems opening it. You need to unpack it into the folder with the pack, which can be found using the [article on installing a file manager](/docs/getting-started/installing-pack#installing-a-file-manager).

</div>
</details>

<details>
<summary>The launcher won't start or can't be installed.</summary>
<div>

Usually, these are problems like *App not supported on your device*, constant crashes on startup, and the like. Most likely, your device is indeed not supported yet. Check that the processor supports the __armeabi-v7a__ architecture, it is necessary to run the game. Or wait for news in [our Discord](https://discord.gg/UbmjP8zeFz), work on supporting 64-bit devices is in progress.

</div>
</details>
