FAQ — Frequently Asked Questions

What is Horizon Modding Kernel?

Horizon Modding Kernel is a flexible game modding launcher, and above all, a mod loader for Minecraft: Bedrock Edition (and possibly other games in the future) on any Android device.

Key features of Horizon Modding Kernel
  • Creating mods for any games that are on your device
  • Replacing existing game resources and adding new ones
  • Flexible API that allows creating stable and powerful environments for game modding
  • Additional support capabilities for Unity, as well as C/C++ applications

You can run mods for Minecraft: Bedrock Edition, the loader provides full backward compatibility with mods for Inner Core. In addition, the launcher has an extensive amount of new functionality, the used version of Minecraft has been updated, and the existing functionality has been refined and stabilized.

All mods developed for Inner Core can be run using Horizon, most of the ports of large mods, such as Industrial Craft, Forestry, Harvest Craft, Blood Magic, etc., have been additionally optimized to work in Horizon.

Where can I find the current version of the launcher?

To start playing with mods, you will need Horizon, in which you will need to load Inner Core.

Download the latest version from this link and install it, allowing installation from third-party sources. Open the application and download the Inner Core pack (or Inner Core Test if you wish to receive updates slightly more often than others), Inner Core Legacy is outdated and is not recommended for installation.

The application may restart to complete the installation, now you can install the desired modifications using the Mod Browser on the pack's main page. To run the modified game, according to the license terms, you must have Minecraft installed. If you do not have it, you can download a dummy without the game itself, it does not take up space and allows the launcher to run. Have a good game!

To get the full instructions, open this documentation page.

External packs are unavailable. You can download and install them manually. What to do?

If external packs are unavailable, most likely the communication provider blocks access to gitlab.com where all versions of Inner Core are located. Almost any VPN will help, after downloading it will not be needed. If the problem is not this, check the site status, perhaps you just need to wait a little.

The mod browser does not download anything, what to do?

If the mod browser is unavailable, most likely the communication provider blocks access to icmods.mineprogramming.org where all mods and modpacks of Inner Core are located. Almost any VPN will help, after downloading it will not be needed. If the problem is not this, perhaps you just need to wait a little.

Can I play with friends over the network?

To play over the network remotely, the device whose world other players want to join must be connected to Wi-Fi. All players must sign in to Xbox Live and add each other as friends (via the tab in the game's main menu). If there are problems, write to our Discord, we will try to solve your problem.

Want more? Download the ZoteCore server core, all further instructions can be found here: Reider745/ZoteCoreLoader.

Why does the launcher crash periodically on startup?

Sometimes crashes happen, this does not happen so often, but sometimes it happens. We have a choice: no crashes on startup, but with crashes in the game, or only sometimes on startup. If the problems persist, you can stop the application and clear the cache, this is enough in most cases.

I have a .icmod archive, how can I install it?

This is a regular zip-archive, change its format if you have problems opening it. You need to unpack it into the folder with the pack, which can be found using the article on installing a file manager.

The launcher won't start or can't be installed.

Usually, these are problems like App not supported on your device, constant crashes on startup, and the like. Most likely, your device is indeed not supported yet. Check that the processor supports the armeabi-v7a architecture, it is necessary to run the game. Or wait for news in our Discord, work on supporting 64-bit devices is in progress.

Where can I get support or ask questions?

We cannot answer every question in advance, but if one arises, we will promptly resolve it in our Discord. Write to the messages for help, or subscribe to the community to track news on released mods and their development.
